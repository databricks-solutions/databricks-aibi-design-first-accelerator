Tools & Models

Supervisor agent toolset and model assignments

Tool Model Purpose Used In Steps
Supervisor Agent (LLM) databricks-gpt-5-5 Orchestrates all tool calls, reasoning, planning All steps
call_vision_model databricks-gpt-5-5 Parse ERD images, extract tables/columns/relationships Data Layer
execute_sql — (SQL Warehouse) DDL, DML, metric view creation, dataset validation Data Layer, Metrics, Dashboards, Genie
execute_python — (subprocess) Generate YAML artifacts, data transformations Metrics, Documentation
execute_notebook — (Jobs API) Run ETL notebooks (DDL, synthetic data via dbldatagen) Data Layer
import_notebook — (Workspace API) Import generated notebooks to workspace Data Layer
create_dashboard — (Lakeview API) Create Lakeview dashboards with serialized JSON Dashboards
publish_dashboard — (Lakeview API) Publish draft dashboards for sharing Dashboards
create_genie_space — (Genie API) Create AI-powered Genie data rooms Genie Space
read_workspace_file — (Workspace API) Read configs, prompts, YAML artifacts, KPI specs All steps
write_workspace_file — (Workspace API) Write YAML artifacts, validation results, docs All steps
describe_table — (SQL Warehouse) Inspect table schemas for metric view design Metrics, Dashboards, Genie
cleanup_path — (Workspace API) Remove temporary or versioned output folders Cleanup
report_progress — (internal) Report phase progress to UI monitoring All steps
report_step_complete — (internal) Signal step completion to orchestrator All steps

All LLM reasoning uses databricks-gpt-5-5 (configurable via LLM_ENDPOINT_NAME env var). Vision calls use databricks-gpt-5-5 (configurable via VISION_ENDPOINT_NAME). Tool execution is deterministic (no LLM) — only the supervisor agent's planning/reasoning loop uses the model.
